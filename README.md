# sharptest

A C# console app that pings nearby Philippine speed test servers, picks the fastest one, then downloads from it using 8 parallel connections.

> [!NOTE]
> **The result reflects that SERVER'S OWN SPEED LIMIT**, not necessarily your real internet speed. 
> This is **Philippines ONLY**. It does not support other countries and the server list in the JSON file of the project was curated by me.

Servers List from [William Yap](https://williamyaps.github.io/wlmjavascript/servercli.html).
